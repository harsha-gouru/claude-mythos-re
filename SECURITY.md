# Security / research scope

This repository is defensive research based on public patches and advisories.

Allowed:

- root-cause analysis of public fixes
- invariant extraction
- scanner design
- patch cards and regression-test sketches
- non-weaponized primitive classification

Out of scope:

- exploit code
- weaponized proof-of-concepts
- bypass recipes
- targeting currently embargoed bugs

If you use this repo, keep outputs at the level of defensive reasoning and patch guidance.
